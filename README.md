# إلى قلبك — رحلة عبر ثلاثة عوالم

## تشغيل النسخة المستقلة
افتح `standalone.html` في متصفح حديث. لا تحتاج إلى تثبيت مكتبات JavaScript. قد يحتاج الخط العربي المخصص إلى اتصال بالإنترنت، لكن التجربة تعمل بخطوط النظام عند انقطاعه.

## تشغيل المشروع المنظم
افتح `index.html`. ملفات CSS وJavaScript منفصلة لتسهيل التعديل.

## تعديل الاسم والرسائل
افتح `js/config.js` وعدّل:
- `recipientName`: اسم الشخص في الكشف النهائي.
- `senderName`: اسم المُهدي (مهيأ للتوسعة).
- `memoryMessages`: عناوين ورسائل الذكريات الخمس.
- `finalMessage`: العبارة النهائية.
- إعدادات الصوت والجسيمات والحركة.

## التحكم
- زر أعلى الشاشة لتشغيل/إيقاف الصوت.
- الفصل الثاني: لمس الأجسام الضوئية الخمسة لاستكشاف الرسائل. زر العودة يعيد الجسم إلى المشهد.
- الفصل الثالث: تفاعل لمس خفيف على القلب والمشهد.
- زر إعادة الرحلة يظهر بعد الكشف النهائي.

## ملاحظات
الرسوم تعتمد على Canvas 2D وجسيمات مولدة إجرائيًا لتعمل على الهاتف من دون تحميل مكتبات خارجية. رابط Google Fonts اختياري لتحسين شكل الخط.
